# 🎬 Netflix Subscription Dashboard (Power BI)

## 📊 Project Overview

This project is an **interactive Power BI dashboard** built to analyze Netflix subscription data, focusing on revenue performance, user demographics, and subscription behavior patterns.

The dashboard provides a clear understanding of:

* 📈 Subscription growth trends
* 💰 Revenue distribution across plans
* 👥 User demographics and behavior insights
* 📋 Subscription plan usage patterns
* 🌍 Region-wise user concentration and distribution

## 🚀 Features

* 📈 Interactive dashboard
* 💰 Revenue analysis
* 👥 User segmentation
* 🌍 Region-based insights
* 📅 Monthly & yearly trend analysis
* 🎛️ Interactive filters and visualizations

## 🛠️ Tools & Technologies

* Power BI
* Excel / CSV
* Data Cleaning & Transformation
* Data Visualization

## 📁 Dataset

**Dataset:** Netflix Subscription Dataset
**Source:** Kaggle

[Kaggle Dataset](https://www.kaggle.com/datasets/olagokeblissman/netflix-user-behavior-and-subscription-dataset?utm_source=chatgpt.com)

## 🎯 Key Insights

* Premium plans have strong user adoption.
* Revenue shows an overall increasing trend.
* Certain regions have a higher concentration of users.
* Subscription preferences vary across user segments.
